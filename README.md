📚 Catálogo de Livros - Documentação
🚀 Visão Geral
Este projeto é um sistema de catálogo de livros que:

Consome dados da API pública Gutendex

Armazena informações em banco de dados PostgreSQL

Oferece operações CRUD completas

Desenvolvido com Java 17 e Spring Boot 3.2.5

🛠 Pré-requisitos
Java 17 JDK

PostgreSQL 14+

Maven 3.8+

IDE recomendada: IntelliJ IDEA
